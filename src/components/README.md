# Sandorių komponentai

- `TransactionForm.jsx` kuria ir redaguoja įnašus, pirkimus bei pardavimus. Jis naudoja pinigų konvertavimo funkcijas, rodo įvesties klaidas prie laukų ir tikrina sandorio bei portfelio validumą; nesėkmingai išsaugojus įvestis paliekamos formoje.
- `TransactionList.jsx` pateikia sandorius chronologine tvarka, rodo sumas eurais ir realizuotą pelną pardavimo eilutėse bei pateikia redagavimo ir trynimo veiksmus puslapiui.

Komponentai naudoja esamą React aplinką ir neprideda naujų bibliotekų.
